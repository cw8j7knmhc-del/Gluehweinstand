Globale Vorlage

Nur bei aktivierter Option wird der Token unverschlüsselt im lokalen Browserspeicher abgelegt. Nur auf einem vertrauenswürdigen Gerät verwenden. Der Token wird niemals in die Vorlagendatei geschrieben. Nur Getränkeliste, Preise, Farben, Reihenfolge und Bechereinsatz werden öffentlich in GitHub gespeichert.

Vorlagen werden ausschließlich manuell gespeichert und geladen. Gerätename und Verkäufe bleiben lokal.

Datensicherung

Sicherung enthält Einstellungen und Verkäufe, aber keinen GitHub-Token. Bitte außerhalb des Geräts aufbewahren.

Diese App ist ein Bestell- und Abrechnungsrechner, keine Registrierkasse. Die Daten liegen ausschließlich lokal auf diesem Gerät bzw. in diesem Browserprofil.
